# 远行簿

一个按时间线整理公开旅行计划的纯静态网站。总站首页统一展示计划和出发时间；每个旅行计划保留自己的页面设计、内容结构与交互，不要求使用统一模板。

## 本地预览

项目不需要安装依赖或构建。建议使用任意静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 项目结构

- `index.html`：总站时间线首页
- `assets/trips.js`：总站卡片数据与独立页面入口
- `trips/jiangnan-2026/`：江南旅行计划独立页面
- `trips/yunnan-2026/`：昆明、丽江、长沙旅行计划独立页面

## 添加旅行计划

1. 在 `trips/` 中加入完整的独立静态网页目录，页面可以使用自己的样式和交互。
2. 在 `assets/trips.js` 的 `trips` 数组中增加首页卡片信息。
3. 将 `page` 指向该页面目录，例如 `./trips/example/`。
4. 确保图片可公开使用，并将内部资源转换为仓库内的本地文件。

## GitHub Pages

推送到 `main` 后，`.github/workflows/pages.yml` 会检查公开内容并部署站点。首次使用时，在仓库设置的 Pages 页面中将 Source 选择为 GitHub Actions。

## 公开内容边界

允许发布：

- 公开旅游路线、城市和概略日期
- 景点、公共交通方式和住宿区域
- 美食、预算范围和通用出行提示

禁止发布：

- 账号、密钥、令牌和环境变量
- 身份证号码、手机号、私人邮箱和精确住址
- 内部域名、内部文档和办公系统信息
- 订单号、航班座位、酒店房号等私密预订信息
