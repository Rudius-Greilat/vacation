# 远行簿

一个按时间线整理公开旅行计划的纯静态网站。首页展示不同出发时间的计划，详情页呈现每日路线、交通、住宿区域、美食和通用提示。

## 本地预览

项目不需要安装依赖或构建。可直接打开 `index.html`，也可使用任意静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 添加计划

在 `assets/trips.js` 的 `trips` 数组中增加一项。首页会按 `startDate` 自动排序，详情页通过 `trip.html?id=<计划ID>` 加载对应内容。

封面图片放在 `assets/images/`，推荐使用 WebP，并确保图片拥有可公开使用的权利。

## GitHub Pages

推送到 `main` 后，`.github/workflows/pages.yml` 会执行公开内容扫描并部署站点。首次使用时，在仓库设置的 Pages 页面中将 Source 选择为 GitHub Actions。

## 公开内容边界

允许发布：

- 公开旅游路线、城市和概略日期
- 景点、公共交通方式和住宿区域
- 美食、预算范围和通用出行提示

禁止发布：

- 账号、密钥、令牌和环境变量
- 身份证号、手机号、私人邮箱和精确住址
- 内部域名、内部文档和办公系统信息
- 订单号、航班座位、酒店房号等私密预订信息
